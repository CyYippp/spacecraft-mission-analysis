# Live requirements status

The external `01-spacecraft-mission-analysis.md` portfolio plan sets scope and
intent. This repository records current implementation and evidence. Status here
is current as of the archived-input increment; detailed criteria and residuals remain in
[verification](verification.md) and [validation](validation.md). `IN PROGRESS`
means some required behaviour or evidence is still missing. `PARTIALLY VALIDATED`
means bounded comparison evidence exists but the full requirement remains open.

| ID | Status | Implementation / evidence | Remaining disposition |
| --- | --- | --- | --- |
| MA-01 — archived TLE input and provenance | VERIFIED | [TleRecord](../src/spacecraft_mission_analysis/orbit.py) preserves exact lines, UTC epoch, catalogue ID and source; the strict [input schema/loader](input-schema-v1.md) requires a source label and constructs `AnalysisConfig`. [Input tests](../tests/test_input.py) cover checksums, malformed lines, pair mismatch, epoch/source preservation, invalid config and archived config→run composition. | Verification is of archived input handling, not orbital truth or a live acquisition/source-history service. |
| MA-02 — SGP4 propagation | IN PROGRESS | [Sgp4Propagator and typed TEME state](../src/spacecraft_mission_analysis/orbit.py) use WGS72 and explicit errors; the [reference-vector verification](verification.md#reference-vector) passes. | Run-level time-since-epoch reporting is not implemented; same-model verification does not establish orbit truth. |
| MA-03 — frames and topocentric geometry | PARTIALLY VALIDATED | [Frame](../src/spacecraft_mission_analysis/frames.py), [station](../src/spacecraft_mission_analysis/stations.py), and [geometry](../src/spacecraft_mission_analysis/geometry.py) modules implement TEME→ITRS→station-relative ITRS→ENU→azimuth/elevation/range. Component [verification](verification.md) passes, including the matched split-UT1 frame reference; downstream geometry passed the [Skyfield Phase B comparison](validation.md#phase-b-first-observed-hold-out-result--pass). | The printed Appendix C discrepancy remains recorded under [ISS-001](issues.md#iss-001--vallado-printed-vector-versus-split-ut1); the shared SGP4 comparison is bounded, not physical geometry accuracy. |
| MA-04 — access events, duration, maximum elevation | PARTIALLY VALIDATED | [Access solver](../src/spacecraft_mission_analysis/access.py) returns refined entry/exit, duration, maximum elevation and UTC peak time. [Analytic tests](../tests/test_access.py) verify roots, peaks, boundaries and grid convergence; the [archived integration test](../tests/test_access_integration.py) checks the full chain. Frozen [Skyfield Phase B](validation.md#phase-b-first-observed-hold-out-result--pass) passed independent downstream event-time comparison under a shared SGP4 kernel. | Peak elevation has no independent comparison; finite sampling can miss narrow access ([ISS-002](issues.md#iss-002--finite-coarse-step-detection)) or an unresolved higher peak ([ISS-006](issues.md#iss-006--peak-search-globality-boundary)). No physical pass accuracy is claimed. |
| MA-05 — versioned outputs and provenance | VERIFIED | [Run/output modules](../src/spacecraft_mission_analysis/run.py) produce [schema 1.0 JSON and CSV bundle](run-schema-v1.md) with UTC/units, complete run configuration, notices and model provenance. [Tests](../tests/test_run.py) require byte-identical reruns within one environment; the saved [archived example](../examples/vanguard_run/) is exact except for optimizer peak fields checked at the already frozen MA-04 limits ([ISS-008](issues.md#iss-008--cross-platform-peak-snapshot-bytes)). The [input composition test](../tests/test_input.py) traces the versioned archived config into this output. | Output-contract verification is not physical-orbit or access validation. Optional source revision must be supplied through build/environment metadata. |
| MA-06 — warnings and failures | VERIFIED | [Run orchestration](../src/spacecraft_mission_analysis/run.py) emits structured 7-day TLE-age and >24-hour comparison-duration warnings, records EOP/SGP4 failures, discards partial outputs and distinguishes successful no-pass. [Fault tests](../tests/test_run.py) include unavailable EOP, SGP4 code 6 and later-station failure. | Warning thresholds are workflow/evidence boundaries, not physical accuracy limits; unexpected programming faults still raise. |
| MA-07 — independent comparison | PARTIALLY VALIDATED | Independent matched split-UT1 frame equations pass [verification](verification.md#active-matched-split-ut1-production-acceptance); Skyfield Phase A and frozen Phase B pass bounded downstream [validation](validation.md). | Skyfield shares `sgp4==2.27` ([ISS-003](issues.md#iss-003--shared-sgp4-validation-boundary)); independent propagation and GMAT comparisons remain future work. |
| MA-08 — temporal station coverage | VERIFIED | [Coverage metrics](../src/spacecraft_mission_analysis/coverage.py) clip and unite detected intervals from one or more stations. [Hand-calculated A–K fixtures](../tests/test_coverage.py) verify duration, fraction, merged count, longest gap and invalid inputs; [archived two-station integration](../tests/test_access_integration.py) checks composition. See the [MA-08 record](verification.md#ma-08-temporal-station-coverage). | This is deterministic temporal arithmetic, not geographic footprint or physical access accuracy. Inherited access-detection limitations remain. |

The [assumptions](assumptions.md), [issue register](issues.md), and
[decisions](decisions/README.md) govern the stated limitations and dispositions.
