# Decision records

Create a short record when an engineering choice changes the agreed baseline,
the meaning of an interface, or the interpretation of verification evidence.
Name files `NNNN-short-topic.md` in chronological order. A record should state
the decision question, context, alternatives, evidence, chosen decision,
consequences, and verification impact. Include the date and any affected
requirement IDs. Do not reconstruct fictional approvals or decisions.

The current orbit boundary and its evidence are described in
[`architecture.md`](../architecture.md) and
[`verification.md`](../verification.md). No separate retrospective decision
record is needed for this setup milestone.
