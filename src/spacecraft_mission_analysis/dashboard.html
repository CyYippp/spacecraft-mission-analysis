01 / Purpose

What this runs

The existing archived-TLE workflow calculates geometric access for fixed stations over the UTC interval in your configuration. Each run gets its own evidence folder.

Application

Engineering use

Use the results to examine early station and data-handling trades. These model outputs are not measured passes or operational predictions; current inputs and separate validation are needed for operations.

02 / Execute

Run analysis

Runs the selected configuration and opens its saved report below.

Configuration file · view or change

The Vanguard example is filled in when available and uses a test-only Earth-orientation table. For another scenario, enter its existing configuration path; relative Earth-orientation files remain relative to that file.
